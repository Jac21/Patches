# Patches

🧶 A backup repository for musical patches and related sound-design resources.

This repository keeps copies of patches for synths and instruments that may otherwise be difficult to recover if a device, application, or storage service disappears. The contents may include presets, banks, MIDI data, and configuration files.

## Contents

The repository is organized by instrument or software name, with patches grouped by category where that information is available. File names and metadata should make it easy to identify:

- the compatible device or application;
- the patch type or instrument family;
- the author or source, when known; and
- any version or format requirements.

## Using a patch

1. Identify the device or application listed in the patch filename or accompanying notes.
2. Open the manufacturer's or application's documentation for its import/export instructions.
3. Import or load the patch using the supported format for that device.
4. Check gain, velocity, routing, MIDI channels, and external dependencies before playing or recording.

Patch formats are often device-specific. Verify compatibility before copying or restoring a file.

## Backups

When adding patches, preserve the original file name and format when practical. Include an export or textual description if binary formats are the only option, and note:

- the device, plugin, or software and its version;
- the patch name and category;
- the original author or source; and
- any required MIDI, modulation, sample, or preset dependencies.

Do not upload files unless you have permission to redistribute them.

## Contributing

Contributions are welcome when they preserve useful and shareable patch data.

1. Create a branch for the new patches.
2. Place files under a directory matching the instrument or application.
3. Avoid including personal, account, or license information.
4. Open a pull request with a brief description of the additions and compatibility details.

## License

A license may need to be assigned to clarify how repository contents may be used and redistributed. Preserve the license or usage terms of any third-party patch.
